# Tienda Don Pedro

**Tienda Don Pedro** es un proyecto práctico que representa la organización de una tienda de barrio. Su propósito es registrar productos, precios, clientes, pedidos, domicilios, fiados y descuentos de manera sencilla.

## ¿Qué vende Don Pedro?

La tienda ofrece productos de consumo diario, entre ellos:

- Arroz.
- Leche.
- Pan.
- Huevos.
- Otros productos básicos para el hogar.

## Organización del proyecto

La información de la tienda está organizada dentro de la carpeta `datos`, donde cada archivo almacena información específica.

| Archivo | Descripción |
|---|---|
| `productos.txt` | Productos disponibles y sus precios. |
| `clientes.txt` | Registro de los clientes de la tienda. |
| `fiado.txt` | Registro de compras fiadas de los clientes. |
| `descuentos.txt` | Descuentos para clientes frecuentes. |
| `domicilios.txt` | Barrios y tarifas de los domicilios. |
| `pedidos.txt` | Archivo temporal utilizado durante la práctica. |

## Cambios realizados

Durante el desarrollo de esta actividad se realizaron los siguientes cambios:

1. **Productos:** se agregó arroz y se actualizaron precios.
2. **Clientes:** se agregó un nuevo cliente.
3. **Pedidos:** se creó y posteriormente se eliminó el archivo de pedidos.
4. **Fiados:** se incorporó el registro de clientes con compras pendientes.
5. **Descuentos:** se agregó información sobre descuentos para clientes frecuentes.
6. **Precios del pan:** se trabajó con ramas para modificar el precio y resolver un conflicto.
7. **Domicilios:** se agregaron barrios con sus respectivas tarifas.
8. **Conflicto de precios:** se provocó y resolvió un conflicto con el precio de los huevos, dando prioridad al precio de la promoción.
